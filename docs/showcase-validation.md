# 案例说明与验证范围

日期：2026-10-03。案例状态：本地 Candidate，指定检查通过，真人审美待验收。

## 1. 研读桌：从一句需求开始

**原始需求**：中文 AI 阅读笔记产品，像一本安静的杂志；粘贴文章、整理要点、保存、列表查看与编辑；等待时不空白、详情切换柔和；支持电脑与手机，AI 为本地模拟。

**设计选择**：纸白/墨色/朱红、阅读排版；桌面目录与正文双栏，手机每次聚焦一个任务。等待用静态骨架，不虚构百分比；详情短暂淡入，减少动态偏好下取消动画。

**代码**：[研读桌](../examples/reading-desk/)。独立执行 Agent 按候选 Skill 读取规则并实现，主 Agent 统一做浏览器验收。

**真实浏览器验证**：空输入错误定位；整理/取消/再整理；保存、编辑、刷新读回；390 宽列表/详情/编辑；长标题和 768 中宽；减少动态时详情 animation=none、duration=0s。

**首轮发现与修复**：生成完成后焦点落到页面 body。改为仅在焦点丢失或停留原触发者时移动到结果标题；实际回归 focus=draftHeading。经历一轮聚焦修复，不能声称一次生成即完成。

## 2. 投递手记：保留功能与数据的改造

**原始需求**：已有能新增、编辑、搜索、保存记录的粗糙 demo，希望日常好用、电脑手机适配，不丢原数据。

**设计选择**：列表优先、状态筛选、按需编辑弹窗；宽屏保留表格比较，窄屏转为记录卡片；区分首次空态、搜索无结果与保存失败。

**代码**：[改造后与原始版本](../examples/application-tracker/)。虚构公司和岗位仅用于测试。

**真实浏览器验证**：改造前通过页面创建记录，改造后直接读到原岗位与备注；新增/编辑/搜索清除/刷新；字段校验失败保留其他输入；390 宽编辑保存；弹窗 Enter/Escape/Tab/Shift+Tab 指定路径；768 宽动作列。

**首轮发现与修复**：原生弹窗末尾 Tab 逸出，补显式双向边界；768 宽“编辑”按钮换行，调整动作列间距与不换行。两轮修复后真实浏览器回归通过。

## 3. 效果体验室：把“我说不出名字”变成可比较的选择

[体验室源码](../examples/effect-studio/)提供等待反馈、详情切换、排版和保存反馈的固定演示。它帮助比较设计取舍，不具备自然语言识别能力；理解用户语言、推荐效果由 Codex 和 Skill 完成。采用本地模拟状态，不是接入模型的线上产品。

## 证据怎么解读

| 证据 | 已做 | 不能据此宣称 |
|---|---|---|
| 隔离运行 | 两个新增案例的 verify.cjs；主项目已有15项QA/AI契约测试 | 替代真实浏览器或真实服务 |
| 浏览器 | 上述具体主路径、桌面/390/768、截图、指定焦点与减少动态 | 完整设备/键盘/读屏覆盖 |
| 独立复核 | 复跑脚本、查看候选6张截图、核对18项原案例文件散列 | 独立重演全部浏览器交互 |
| 真人体验 | 尚未完成 | 审美认可、真实新手独立使用成功 |

旧版与新版各做过同一新建 brief 的样例，但旧快照缺一份可选 sample，且只各生成一次。两者主流程都能通过，不能由此证明新版稳定更好或计算提效倍数。执行使用冻结候选规则，之后的审核措辞一致性修订仅做静态复核。

当前公开准备的 HTML/验证脚本来自已验收案例，仅进行发布所需的行尾空白清理；本页是可分享摘要，不包含本机路径、浏览器日志或私有资料。没有验证真实 AI 内容质量、真实手机软键盘、屏幕阅读器/完整WCAG、浏览器存储故障注入、跨浏览器兼容或生产上线。
