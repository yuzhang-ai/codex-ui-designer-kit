# 案例：研读桌 v1 → v2

> 这份案例是**改版过程记录**，给维护者和想了解方法的人看。生成新页面时不必读它，以免照搬这个产品的答案。规则本身已经写进 `references/visual-taste-corrections.md` 和 `references/visual-signature.md`。

需求：“我没有设计经验，希望像一本安静的杂志。粘贴文章后整理要点，能保存、查看和编辑；电脑手机都能用。”源码见 [examples/reading-desk/](../../examples/reading-desk/)，设计记录见同目录的 [DESIGN.md](../../examples/reading-desk/DESIGN.md)。

## v1 的问题

| 问题 | 手册条目 |
|---|---|
| 顶栏、侧栏、每条笔记、每个区块之间都有 1px 线，没有分工 | 2.1 |
| 圆角 2–4px，和“安静”的方向不符 | 2.2 |
| 朱红同时用于主按钮、眉题、序号、标题聚焦框和成功提示 | 2.4 |
| 阅读内容用无衬线、标题用衬线，字体角色混乱 | 2.7 |
| “READ · THINK · KEEP”“READING NOTES / 阅读手记”装饰性英文 | 2.8 |
| 1440 宽度下正文贴左 | 2.9 |
| 文章标题被重复摘成第 1 个要点 | 2.10 |

## 第一次修改：编辑杂志方向

改成宋体阅读、墨色主按钮、朱红只留给印章与序号，修好标题重复和宽屏居中，但保留了大量细线和直角。用户反馈：**“不太喜欢线框感，以及特别直角化的感觉。”**

教训：Agent 把“杂志感”理解成了“细线 + 直角 + 衬线”。这个用户要的“安静”更接近柔和的纸和留白。同一个方向词可以做出完全不同的结果，要在第一张截图后确认。

## 第二次修改：纸页方向

- 删掉所有分割线和描边，改为“桌面 → 纸页 → 内凹面”三层（第 4 节）。这在阅读产品里成立，因为页面没有需要逐行比较的数据。
- 圆角刻度 28 / 18 / 16 / 胶囊。
- 序号改为浅朱底圆形，“我的想法”改为浅朱底色块，元信息改为胶囊标签。
- 手机导航改为浮动分段胶囊，编辑页保存按钮改为底部吸附的浮动条。
- 去掉伪斜体，数字改为等高数字，导语消除孤字。

用户反馈：整体好很多，但**“牛皮纸颜色的背景上放一个黑色按钮，有点怪。”**

## 第三次修改：主操作颜色

- 主按钮从墨黑 `#1d1b18` 改为胡桃褐 `#5a4030`，和背景同一暖色相，文字对比度 8.8:1（2.3）。
- 侧栏“开始新的阅读”降为次级按钮，一屏只剩一个深色块（2.5）。
- 手机导航选中项从深色实底改为抬起的纸色胶囊。

## 可以带走的做法

1. 用户说“安静、杂志、高级”时，先把它翻译成面、形状、线和主色的具体用法，第一张截图后向用户确认。
2. 每条线、每个容器都要有职责；说不出职责的先试留白和底色面。
3. 有色背景上的主操作，优先取同色相的深色。
4. 一个任务区域一个主操作；强调色的角色写进 DESIGN。
5. 每次改完在 1440 / 768 / 375 截图，并把用户原话和对应改动记进 DESIGN。
