# 视觉设计提炼：从规则检查转向设计推导

日期：2026-10-04。状态：本地方法候选，尚未用新任务验证生成效果。

## 当前问题与范围

此前Skill已有参照、tokens和视觉验收项，但从产品定位到风格形成的推导不足；字体缺少实际字族/回退/字距决策，icon多停留于尺寸笔画一致，信息组织容易退化为“少一点文字”。便签试验用户明确不认可并终止，不再作为案例推进，历史构建/交互通过不抵消视觉反馈。此次不新增或打磨产品案例。

本轮读取下列官方正文；重新查看10月3日本地留存的Notion侧栏和飞书表格官方图。Linear文章浏览器文字可读，但对照图未成功显示且图片读取失败，因此只采用作者明确说明，不宣称看到了改版细节。Notion 2026复盘亦按正文证据处理。未登录测试这些产品，未测精确像素或实际字体。

## 一手来源与可迁移判断

| 来源与边界 | 明确事实（摘要） | 我们的推导与迁移边界 |
|---|---|---|
| [Linear 2026-03-12设计复盘](https://linear.app/now/behind-the-latest-design-refresh)，官方正文 | 围绕任务内容降低导航权重，收敛图标与分隔；在产品内调整主题token并同步设计资料 | 先决定谁应该占据注意，再联动图标/文字/边界；这不意味着所有项目都缩小导航或采用深色。工程试排应反馈到规范 |
| [Notion 2026-03-18页面设计复盘](https://www.notion.com/en-gb/blog/updating-the-design-of-notion-pages)，官方正文 | 段落和列表对间距的需求不同；按相邻块类型让连续列表聚合，同时保留段落间距 | 空间规则可依内容关系变化；不把所有间距强制相同。适用于混合文档，不能直接套到数据表行距 |
| [Fluent字体](https://fluent2.microsoft.design/typography)，官方规范 | 按语义角色组织字体参数，考虑平台字族，结合对齐与颜色形成层次 | 学习角色体系，不把Segoe或Web正文14/20当中文通用答案 |
| [Fluent图标](https://fluent2.microsoft.design/iconography)，官方规范 | 系统图标表达对象/概念/动作；regular和filled有不同状态用途，图标与交互尺寸需结合场景 | 先建语义映射再选图；图标尺寸不是点击区域，不把全部实心化当升级 |
| [Carbon排版](https://www.carbondesignsystem.com/building-blocks/foundations/typography/overview)，官方规范 | 区分任务型与表达型排版，IBM Plex与其字阶共同设计 | 用阅读/操作方式选择密度；不能换成别的字族却假定整套关系原样成立 |
| [Ant Design字体](https://ant.design/docs/spec/font/)，官方规范 | 字族、字号行高、字重和颜色作为系统设计；需要按列比较的数字可使用等宽数字 | 中文工程要实测混排与fallback；14/22是其系统参考，不是成熟感公式 |
| [Fluent布局](https://fluent2.microsoft.design/layout)，官方规范 | 空间表达关联，网格可固定、伸缩或混合，光学对齐可以调整间距 | 栅格需回答区域职责，不能用统一倍数替代组合判断 |

## 两个官方图的关系拆解

来源与原图时间边界沿用 [上一轮调研](product-benchmark-research.md)，本轮重新目视检查存档，不作为最新线上截图：

- **Notion帮助中的侧栏/内容图**：浅底侧栏与内容分工，导航符号、页面标识和正文复选框职责不同。推导：同一界面图形不必全画法一致，但同类角色需一致。外层帮助站导航、红色教学箭头不属于产品；不能由图判定字体名/字距。
- **飞书分组表格图**：任务名、执行人、状态、日期保持固定列位，分组行与记录行不同。推导：成熟的密度来自字段选择与比较关系，不是简单缩字。图有教学灰蒙层与高亮，不提取颜色/对比数值，不照抄人物或示例业务数据。

## 落入Skill的方式

入口在新建/整体改造的视觉方向阶段读取 visual-design-derivation；DESIGN承载定位、因果提取、排版与icon约定；project-design-contract承接到代码；评审表检查定位与风格是否一致。保持单一来源，不在每份文件复制全套方法。

验证分层：文档链接/入口可达与维度覆盖可静态检查；独立Agent可审查方法是否可执行；尚未运行新的页面生成，不填视觉效果通过。全局安装与GitHub同步不在本次范围。
