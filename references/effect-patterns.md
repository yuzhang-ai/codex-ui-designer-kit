# UI 与动效候选检索表

这些是本 Kit 的场景化建议，不是关键词匹配器。优先按主任务选，再依据真实页面修正。

## 视觉与结构

| 用户口语 | 可考虑的模式 | 可见结果与适用场景 | 取舍 |
|---|---|---|---|
| 像安静的杂志、阅读舒服 | Editorial typography / 编辑式排版 | 有节奏的标题、留白、稳定正文栏；阅读/内容产品 | 字体效果不能牺牲中文可读性，正文不持续移动 |
| 干净、有秩序 | Grid + type hierarchy / 网格与字阶 | 对齐、重复间距、明确主次；通用产品 | 干净不等于删掉任务必要信息 |
| 几块内容像拼好的展示板 | Bento grid / 便当盒网格 | 大小模块突出主次；能力展示 | 不是密集数据表的替代品，小屏按阅读顺序重排 |
| 有玻璃层次、像悬浮面板 | Translucent surface / 半透明材质 | 背景透出、前后层次；局部面板 | 对比、性能与后备实色；不要全站滥用模糊 |
| 信息很多但好找 | Dense workbench / 紧凑工作台 | 分组、筛选、列表详情、稳定操作区 | 先任务结构再装饰，不靠挤小字号 |

## 等待与反馈

| 用户口语 | 候选模式 | 适用条件 | 实现与避免项 |
|---|---|---|---|
| 别一加载就白一片 | Skeleton / 骨架屏 | 内容结构已知、正在等内容 | 预留相近空间、标为加载；失败要退出骨架；可用静态骨架 |
| 让我知道它还在做 | Inline status / 局部状态 | 时长未知的任务 | 实际 running 事件驱动文字/轻动画，保留适用的取消；不伪造百分比或推理步骤 |
| 想看到做到哪一步 | Determinate progress / 确定进度 | 上游提供可信进度或真实阶段 | 百分比来自数据；没有数据就显示不确定等待，不定时假进度 |
| AI 能边写边看吗 | Streaming / 流式呈现 | 服务真正提供增量内容 | 显示收到的内容，避免用户阅读时强制滚底；无流接口不能伪称流式生成 |
| 按了要有反馈 | Micro-interaction / 微交互 | 按压、选择、保存等局部动作 | 轻微颜色/形变＋状态文字；成功只由实际成功事件触发 |
| 完成时轻轻提醒 | Inline confirmation / 局部确认 | 不必打断的完成反馈 | 明确可读、读屏可感知；关键反馈不只短暂闪过，不默认满屏彩纸 |

## 切换与出现

| 用户口语 | 候选模式 | 适用条件 | 实现与避免项 |
|---|---|---|---|
| 别突然蹦出来 | Fade / 淡入淡出 | 同层内容更新、安静阅读 | 尽快展示可用内容；不为播放动画强制等候 |
| 像从旁边打开一层 | Slide panel / 侧滑详情 | 主列表与次级详情关系 | 布局边界清楚；模态须焦点管理/Esc，非模态不要假装模态 |
| 卡片自然变成详情 | Shared-element / 共享元素转场 | 同一对象在两个视图之间 | 对象身份稳定，可用 View Transition 渐进增强；无支持时即时/淡入 |
| 列表依次轻轻出来 | Stagger / 错峰出现 | 首次出现、低频少量内容 | 总延迟有界；筛选/实时列表不反复重播；减少动态时直接显示 |
| 更有弹性、像按得动 | Spring / 弹簧响应 | 拖拽、直接操作反馈 | 限制回弹和位移；密集文字、错误提示不跳动 |
| 滚动时像讲故事 | Scroll reveal / 视差叙事 | 营销叙事、展示区域 | 正常滚动优先，不劫持滚轮；阅读正文保持稳定，减少动态时取消位移 |

## 实施规格与降级

为真正采用的效果填 DESIGN 表，不给所有页面默认加动画。可从轻反馈 120–180ms、内容切换 180–260ms、小位移 4–12px 起步，再在目标设备看实际效果；这些是本 Kit 建议起点，不是官方硬标准。优先局部 opacity/transform，性能仍需实测。CSS 能完成时不为一个淡入新增库。

响应用户或系统的减少动态效果偏好：取消非必要位移/缩放/回弹/连续闪动，保留即时内容和文字状态。CSS 与 JS 两侧都检查；状态完成不能依赖 animationend。重复触发可取消/替换旧动画，不延迟真实业务结果。

## 本轮核验的一手资料（2026-10-03）

- Carbon loading：区分加载反馈、内容骨架及局部状态。https://www.carbondesignsystem.com/building-blocks/core/components/loading/guidelines
- W3C SC 2.3.3（AAA）：用户可关闭非必要交互动效；引用不等于本项目达到整套 WCAG。https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html
- MDN 减少动态效果：https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion
- MDN View Transition：使用前核验目标浏览器支持与后备方式。https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API
