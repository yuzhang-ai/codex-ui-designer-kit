# 投递手记 · 设计记录（v2）

状态：Candidate。机器检查与浏览器主流程已通过，真人审美尚未验收。

## 方向

每天打开的投递清单。浅鼠尾草色桌面上放一张圆角工作面，记录是第一重点，新增投递是唯一主操作。

这是数据工具，和研读桌不同：用户要逐行比较公司、进展和备注，所以**记录行之间保留极淡的行线**，行线从内容起点开始，不贯穿到工作面边缘。除此之外的分区（顶栏、工具栏、表头、页脚）都去掉了线，改用留白和底色面。这对应 `references/visual-taste-corrections.md` 2.1 里“线要有分工”的规则。

## v1 → v2

| v1 | v2 |
|---|---|
| 白色顶栏 + 底线，工作区外框 + 工具栏底线 + 每行顶线 + 页脚顶线 | 顶栏直接放在桌面上；工作面无描边，用投影浮起；只保留记录行之间的淡行线 |
| 输入框、搜索框灰色描边，圆角 8 | 无描边填充面，搜索框为胶囊，聚焦时变白并出现细松绿外圈 |
| 按钮圆角 8，次按钮白底描边 | 全部胶囊；次按钮为浅色填充面 |
| 筛选是一排文字按钮，选中项浅绿底 | 分段胶囊，选中项为抬起的纸色胶囊 |
| 状态标签是方角色块 | 胶囊标签 + 圆点，颜色仍区分三种进展，文字也写明进展 |
| “MY APPLICATIONS”装饰性英文眉题 | 删除 |
| 页脚“记录进展，按自己的节奏前行”和底部说明重复讲本地存储 | 页脚只写“数据只保存在当前浏览器”，底部说明只补充丢失和同步的风险 |
| 成功提示是浅绿描边条 | 实心浅绿条 + 对勾圆标；失败为浅红条 + 感叹号 |
| 手机端记录之间用线分隔 | 每条记录是一张圆角卡片，备注放在卡片内的浅色面里 |

## Tokens

- 面：`--desk` 桌面，`--sheet` 工作面与对话框，`--well` 输入框、筛选底、页脚。
- 色：`--pine #2f5a45` 主操作（与背景同一绿色色相），`--ink` 正文，`--muted` 说明（工作面上对比度 ≥4.5:1），`--error` 错误。
- 状态：待投递灰、已投递蓝、面试中绿，均配圆点和文字。
- 圆角：工作面与对话框 24，手机记录卡片 16，输入 14，按钮、标签、筛选为胶囊。
- 阴影：`--lift-hi` 只给工作面；`--lift` 给筛选选中项和手机记录卡片。

## 保留不变

数据键 `uikit-job-demo-v1`、字段、新增、编辑、搜索、筛选、保存失败保留输入、焦点循环等全部逻辑没有改动，只换了样式和三处文案。
