# 研读桌

UI Designer Kit 候选流程的真实执行案例。单文件 HTML，无需构建或安装前端依赖；所有演示内容均为本地测试数据，未连接后端或真实 AI 服务。

## 运行

在仓库根目录执行：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8000/examples/reading-desk/`。直接打开 index.html 也能预览，但浏览器对 file:// 本地存储的行为可能不同，建议固定 localhost 地址体验。

数据仅存在当前浏览器。不同端口、主机名或浏览器不会自动共享；清除站点数据会丢失记录。不要用该示例保存重要资料。

## 验证

在本目录执行 `node verify.cjs`，使用 Node.js 22 或以上。脚本验证 DOM/storage 替身下的逻辑；它不启动浏览器，也不证明视觉或无障碍合规。

本案例已有指定浏览器主流程、桌面/390/768 宽度检查。首次缺陷与修复、精确验证边界见 [案例记录](../../docs/showcase-validation.md)。真人审美尚未验收。

## 模拟 AI 的边界

整理采用本地规则摘取原文句子。等待动画仅演示状态，不能代表真实推理速度或内容理解能力。生成结果可编辑，点击保存后才进入笔记列表。
