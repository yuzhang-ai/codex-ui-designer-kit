# 研读桌 · 设计记录（v2）

状态：Candidate。机器检查与浏览器主流程已通过，真人审美尚未验收。

## 方向

书桌上的一页纸。阅读内容放在一张圆角纸页上，纸页浮在暖色桌面之上；层级靠面、留白和字号区分，不靠线框。

v1 的问题与本版的处理：

| v1 | v2 |
|---|---|
| 到处是 1px 分割线和直角描边，像表单 | 去掉全部分割线；用纸页、内凹输入面、浅色块分层 |
| 朱红同时用于主按钮、提示、标题聚焦框，强调过多 | 朱红只用于印记、序号和当前位置；主操作改为胡桃褐胶囊按钮 |
| 正文 sans 与标题 serif 混排，阅读区像后台 | 正文、要点、想法、原文统一用宋体，界面标签用无衬线 |
| 标题会被重复摘成第 1 个要点 | 第一行较短且后面有正文时作为标题，不再进入要点 |
| 桌面 1440 宽时正文贴左，右侧空 | 纸页在内容区居中，最大 820px |
| 保存成功提示为红色，像报错 | 普通状态改为墨色，红色只留给失败和校验 |

## Tokens

- 面：`--desk` 桌面，`--sheet` 纸页，`--well` 纸页内输入与折叠区。
- 色：`--walnut #5a4030` 主操作（与纸同一暖色相，文字对比 8.8:1），`--ink` 正文，`--ink-2` 次级，`--muted` 说明（纸色上对比度 ≥4.5:1），`--seal` 朱印，`--seal-wash` 朱印浅底。
- 圆角：纸页 28，块 18，输入 16，按钮与标签为胶囊。
- 阴影：`--lift` 用于选中的目录项和浮动操作条，`--lift-hi` 只用于纸页。
- 字：`--serif` 宋体用于标题和所有阅读内容；`--sans` 用于界面标签；`--figure` 用于序号和计数，使用等高数字，避免 0 被读成 o。

## 组件

- 主按钮：胡桃褐胶囊，带同色投影，每个视图只有一个；次按钮：浅色胶囊（侧栏“开始新的阅读”属于次按钮）；文字按钮：朱红文字，悬停出浅底。
- 输入：无描边内凹面，聚焦时变白并出现细墨色外圈；校验失败为朱红外圈。
- 要点：圆形朱印浅底序号 + 宋体正文，行宽限制在 36em。
- 我的想法：朱印浅底色块，不再用左侧竖线。
- 回看原文：浅色折叠块，右侧“展开 / 收起”标签。
- 手机导航：顶部浮动分段胶囊，当前项为抬起的纸色胶囊。
- 编辑页操作条：底部吸附的半透明胶囊，长内容时保存按钮始终可点。

## 用户反馈与对应修改

1. “不太喜欢线框感，以及特别直角化的感觉。” → 删除全部分割线与描边，改为桌面、纸页、内凹面三层；圆角改为 28 / 18 / 16 / 胶囊。
2. “牛皮纸颜色的背景上放一个黑色按钮，有点怪。” → 主按钮从墨黑改为胡桃褐；侧栏新建按钮降为次级；手机导航选中项改为纸色。

这些问题的通用版本已整理进 `references/visual-taste-corrections.md`。

## 已验证（2026-11-11，Claude 浏览器预览）

- 主流程：空输入校验 → 填入示例 → 整理 → 取消并保留原文 → 再次整理 → 填写想法 → 保存 → 详情。
- 刷新后从目录重新打开笔记，数据读回正常。
- 编辑保存后列表仍为 1 条、标题已更新；模拟 `localStorage.setItem` 抛错时显示失败提示，编辑内容保留在页面上。
- 1440 / 768 / 375 宽度无横向溢出；375 宽度下可见按钮高度均 ≥32px，主要按钮 ≥42px。
- 已移除所有 `border-top / border-bottom / border-left` 分割线。
