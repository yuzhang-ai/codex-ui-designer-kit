# UI 效果体验室

用浏览器直接打开 index.html；或者在本目录执行 python -m http.server 3218 --bind 127.0.0.1 后打开 http://127.0.0.1:3218。

四组对比：等待轮廓/任务状态、淡入/侧滑、编辑式/紧凑排版、就地确认/按钮状态。
用途：帮助不懂术语的用户在同内容下比较、表达偏好；不是生产产品或模型服务。
所有状态通过按钮模拟，不联网、不保存、不伪造真实进度。减少动态效果开关和系统偏好均生效。生产集成需接真实事件，保留失败/取消和数据契约。
验证：逐组交互、失败恢复、窄屏、减少动态效果。案例范围见 [案例验证说明](../../docs/showcase-validation.md)。
