# Before / After

## Before

- Marketing-like hero dominates a workbench task.
- High-risk actions such as export, delete, and email blast are tiny ordinary buttons.
- Metrics lack period, comparison, and explanation.
- Table is hard to scan and has no stable status model.
- Mobile layout is forced to desktop width.

Desktop screenshot: `.design/screenshots/before-desktop.png`  
Mobile screenshot: `.design/screenshots/before-mobile.png`

## After

- Converted into a SaaS / CRM workbench with navigation, filters, KPI cards, account table, and state coverage.
- Main action is clear: create follow-up.
- Risk action is separated and labeled as requiring review.
- Account rows use consistent health tags, owner, last touch, and next action.
- Mobile layout converts navigation, filters, metrics, and table rows into usable single-column sections.

Desktop screenshot: `.design/screenshots/after-desktop.png`  
Mobile screenshot: `.design/screenshots/after-mobile.png`

## Verification

- After desktop QA: no blank risk, no horizontal scroll, no text overflow, no small button candidates.
- After mobile QA: no blank risk, no horizontal scroll, no text overflow, no small button candidates.
