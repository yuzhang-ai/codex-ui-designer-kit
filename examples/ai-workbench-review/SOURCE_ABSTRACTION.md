# Source abstraction register

Only generic rules and new synthetic fixtures are included. No private original text, screenshot, asset or system path is redistributed. Private identifiers and provenance remain in the ignored local evidence directory.

| New rule | Fact input | Why generalize | Concrete kit output |
|---|---|---|---|
| Separate task/progress/output/artifact | Authorized knowledge-base notes organize task-specific modules; chat is one possible entry | A changing task needs state and target outside conversational text | Playbook UI mapping and transition phases |
| Keep existing components/tokens | Knowledge-base notes prioritize existing standards, spacing/copy/accessibility | Avoid a redesign that breaks mature host controls | No new component dependency; host integration checklist |
| Element-level evidence + human review | Knowledge-base QA notes bind issues to concrete elements and human signoff | Screenshot appearance does not establish task completion | Evidence fields and blank acceptance matrix |
| One canonical artifact | Knowledge-base notes describe human/script/Agent access to a shared node model; editor standards require shared object semantics | Parallel stores drift across preview/editor/AI | Session document + version identity; host adapter requirement |
| Schema + observation before preview/apply | Private capability audit recorded avoidable schema guessing and scoped operation limits | Unsupported input should fail closed, not create silent writes | Schema/safety/stale/scope/device rejection tests |
| Preview→Apply→Readback→Undo | Private browser audit verified only named compile/apply/safety/Undo/preview/save-refresh subsets | Claims need exact effects and recoverability | One write/history step, readback and restoration tests |
| Unknown does not mean retry | Private AI acceptance plan requires bounded stop and no replay of uncertain mutation | Retrying uncertain writes can duplicate effects | unknown/reconcile/late-callback tests |
| Independent evidence tiers | Private full acceptance summary retained FAIL/HOLD despite local machine/build passes; real model stage remained unexecuted | Green scripts must not upgrade browser/model/external acceptance | verifier labels synthetic Candidate; matrix blank for higher tiers |

Knowledge-base statements are research input, not independently verified claims about the named external tools. Private editor evidence belongs to the dated audit, not this kit's implementation or this run's real-model proof. The portable protocol deliberately omits company catalog/version identifiers and implementation-specific geometry numbers.
