# 青岚能源 · 电站运营台 · 设计记录

状态：**目标样张（target sample）**，由资深产品设计视角逐轮手工打磨，不是 Codex 一次生成的结果。用来展示本 Kit 在高密度数据工具上应该达到的视觉和交互水准。所有数据均为虚构的演示数据，页面上有“演示数据”标签。

单文件 `index.html`，CSS、JS、图标、图表全部内联，不加载任何外部资源，直接用浏览器打开即可。

## 方向

运营负责人每天早上打开它，要回答三件事：12 座电站今天发电是否符合预期，哪几座需要处理，该派什么单。

- **第一视觉重点**：全站“实际 vs 预测”曲线，以及右侧“需要处理”列表。
- **分层**：冷瓷色页面底色 → 白色工作面（同色相软阴影浮起）→ 面内浅灰控件底 / 分组底。同一层内不加描边。
- **气质**：浅、安静、精确。没有渐变 KPI 卡、霓虹、玻璃拟态，也没有装饰性英文。
- **一屏一个主操作**：概览态没有实心按钮；打开电站详情后，唯一的实心深青按钮是“派单”。派单对话框里唯一的实心按钮是“确认派单”。

### 主色负责的角色（只有三种）

1. 主操作（派单、确认派单）
2. 选中（导航当前项图标、选中行的左侧色条和浅底、分段控件不另用主色）
3. “实际发电”这一数据系列（主图曲线、柱、小图、sparkline、完成率条中的正常段）

聚焦外圈也用深青，属于可达性要求，不算视觉强调。成功提示用深色 toast 加对勾，没有借用错误色。

## 线的职责

| 线 | 职责 |
|---|---|
| 表格行之间 `--rule`（7.5% 墨色，inset 1px） | 分隔需要逐行横向比较的电站；悬停和选中行及其下一行去掉线，避免和底色叠加 |
| 工单列表行线 | 同上，逐条比较状态 |
| 详情面板底部操作区顶线 | 标出固定操作区和可滚动内容的边界 |
| 图表网格 `#edf1f3`、基线 `#d9e1e4` | 读数参考，1px 实线 |
| 预测线（虚线） | 区分“预测”和“实际”，虚线只用在这里和 sparkline 的预测上 |
| 事件旗标（红色点线） | 标出跳闸时刻 |

没有卡片描边、标题下划线、区块分隔线。

## 组件

- **导航栏**：84px 竖栏，图标在上、文字在下，同一套 1.6px 圆头描边图标（自绘 SVG sprite）。当前项是抬起的白色胶囊，图标变深青。告警角标显示未读数，随“标记已读”更新。
- **顶栏**：标题 + 日期/更新时间 + “演示数据”胶囊；右侧时间范围分段（今日 / 7天 / 30天）和胶囊搜索框。
- **KPI 卡**（4 个）：指标名 → 大数字 + 小单位 → 带方向箭头的差值 + 比较基准（“比预测 3,584 MWh”）。差值颜色表示好坏：低于预测为红，高于为绿，四舍五入为 0 时用中性色和 ± 号。
- **需要处理**：每个异常电站一个浅底按钮：状态图标块、名称 · 状态、今日少发电量、最新告警时间和原因。点击打开详情。
- **电站表**：电站（名称 + 地区 · 装机）、状态胶囊、当前功率、今日功率 sparkline、发电量、完成率（条 + 百分比，竖刻度为 100%，条宽按 110% 满格）、PR、未读告警。表头可排序，排序列加粗并显示方向箭头，`aria-sort` 同步。状态筛选是带计数的 radiogroup，支持左右方向键。
- **详情面板**：名称、状态、地区 · 装机 · 逆变器数；三格关键数（当前功率 / 完成率 / 可用率）；今日功率小图；逆变器格（正常浅青、降额琥珀 + “!”、离网红 + “×”，有图例和计数文字）；告警时间线（未读标签、已派单标签）；底部“标记已读”（次级）和“派单”（主）。
- **派单对话框**：原生 `<dialog>`。指派给、优先级、处理说明（根据电站预填）。提交中按钮禁用并显示“正在派单…”。
- **空状态**：图标圆 + “没有符合条件的电站” + 具体原因（关键词和筛选条件）+ “清除筛选”。
- **加载**：切换时间范围时，KPI 数字换成骨架条，图表和表格保持原画面降到 40–45% 不透明度，约 0.5 秒后替换。不出现整页闪白和布局跳动。

## 图表规则

- 全部手写 SVG，无图表库。曲线用单调三次插值，平滑但不会冲出负值。
- **今日**：每 30 分钟一点。实际为 2px 深青实线 + 8% 面积；预测为 1.5px 灰色虚线；实际低于预测的部分填浅红（20%）。“现在 14:20”竖线之后为浅灰底，表示尚未发生。现在点直接标注“686 MW / 预测 719 MW”，10:42 跳闸用红点旗标标注。
- **辐照度**：不做双 Y 轴。放在主图下方的独立窄带，共享 X 轴，标注峰值，tooltip 里给出数值。
- **7 天**：每小时一点，按天分段并以细竖线分隔，X 轴标“11/6 周五 … 今天”。
- **30 天**：每日柱（≤16px，顶端 4px 圆角）+ 预测短横线；低于预测 5% 以上的柱变浅；最后一根是今天（截至 14:20），更浅并在注释里说明。
- **悬停**：十字线吸附最近的数据点，tooltip 先给数值后给名称，列出实际、预测、偏差、辐照度，用线段图例而不是色块。图表可聚焦，方向键 / Home / End 移动，Esc 隐藏。tooltip 只是增强，数值在表格和直接标注中都能读到；SVG 有 `role="img"` 和动态文字描述。
- **小图 / sparkline**：同样的实际实线 + 预测虚线语言，sparkline 不加坐标轴。

## 布局与断点

| 宽度 | 布局 |
|---|---|
| ≥ 1280（设计稿 1440） | 三栏：84px 导航 / 主区 / 384px 右栏。右栏默认是“需要处理 + 今日工单”，选中电站后切换为详情。 |
| 1024–1279 | 右栏改为右侧抽屉（遮罩 + 背景 `inert`）；“需要处理”移到 KPI 下方成为三列卡。 |
| 641–1023（设计稿 768） | 导航收为 68px 纯图标（文字保留给读屏）；KPI 2×2；“需要处理”单列；表格隐藏 sparkline 和 PR 两列，其余列不横向滚动。 |
| ≤ 640（设计稿 375） | 底部固定导航（5 项，图标 + 文字，高 52px）；时间范围和搜索各占一行；KPI 2×2，只保留差值；表格换成电站卡片（名称、状态、三项数值、完成率条）；详情为全屏 sheet，操作栏固定在底部并留出安全区。 |

所有宽度都没有页面级横向溢出（实测 375 / 768 / 1440 的 `scrollWidth` 等于 `clientWidth`）。

## 状态与交互

| 动作 | 结果 | 焦点 |
|---|---|---|
| 切换 今日 / 7天 / 30天 | 面板级骨架 → KPI、主图、表格、标签文字一起更新；“需要处理”的少发电量始终是今日 | 留在分段按钮 |
| 排序 / 筛选 / 搜索 | 即时更新；无结果显示具体原因和“清除筛选” | 清除后回到搜索框 |
| 点电站行、卡片或“需要处理”项 | 打开详情；窄屏为抽屉/全屏，背景 inert | 移到关闭按钮 |
| Esc / 关闭 / 点遮罩 | 关闭详情 | 回到触发它的元素 |
| 标记已读 | 未读标签、表格告警列、导航角标同步减少，toast 提示 | 移到“派单” |
| 派单 → 确认 | 0.9 秒提交中 → 成功：对话框关闭，工单列表新增一条，告警时间线出现“已派单 GD-…”，toast 提示 | 回到“派单” |
| 派单失败 | 对话框不关闭，顶部出现红色说明块（图标 + “派单没有发出” + 原因 + “内容已保留”），按钮变为“重试派单”，所有输入保留 | 回到处理说明 |
| 对话框打开时按 Esc | 只关闭对话框，不关闭详情 | 回到“派单” |

### 如何触发派单失败

任选一种：

1. 在“处理说明”里写入 `#fail`（任意位置）后点确认派单。
2. 用 `index.html#fail` 打开页面，第一次派单会失败，重试会成功。

### 截图参数（仅用于截图）

在 URL hash 中使用，例如 `index.html#shot&sel=dhx`：`shot` 关闭所有过渡动画；`range=week|month`；`sel=<电站 id>` 打开详情（`dhx` 敦煌西故障、`gem` 格尔木南预警、`hmd` 哈密东预警）；`q=` 预填搜索；`f=fault|warn|ok` 预设筛选；`dlg` 打开派单对话框；`tip=<序号>` 显示 tooltip；`at=chart-card` 滚动到指定区块。

`prefers-reduced-motion: reduce` 时所有过渡和骨架动画降到瞬时完成。

## 复查记录（visual-taste-corrections 第 6 节）

截图用 headless Chrome（2x，手机 3x 通过 375px iframe）。

**第 1 轮**
- 768 宽度整页横向溢出约 45px：`.stack` 网格轨道被 SVG 和长文本撑开。改为 `grid-template-columns:minmax(0,1fr)`，并在 768 收紧表格列距、完成率条宽。
- 1440 KPI 卡里“比预测 719 MW · 装机 1,284 MW”折行，卡片高度不齐；装机移到指标名后面，375 下隐藏。
- 现在点的“686 MW”标签贴在预测虚线上；改到点的左下方。
- 375 X 轴 8 个时间标签挤在一起（“06:0008:00”），事件标签和“现在”标签相撞；窄屏隔一个显示，事件改短标签“跳闸”，“现在”标签改为左对齐。

**第 2 轮**
- 7 天视图的“现在 14:20”和跳闸标签在右边缘相撞，“686 MW”标签压在曲线上；靠右时改为右对齐，非今日视图不再画数值标签。
- 30 天视图的“需要处理”显示“少发 0.0 MWh”（统计口径跟着时间范围走，但那几座站在 30 天内总体并不少发），读起来像数据错误。改为固定显示“今日少发”，和告警口径一致（对应 2.10：先查数据）。
- 30 天视图漏了今天、可用率出现“−0.0 点”；补上今天的部分柱（浅色并注明），差值四舍五入为 0 时用中性色 ±。
- 今日发电 KPI 下的进度条与差值重复表达，且只有一张卡有，四张卡不齐；删除。
- 表头未排序列的箭头常显，八个箭头形成噪声；改为只在悬停/聚焦和当前排序列显示。
- 设置图标原来像太阳，和辐照度语义冲突；换成滑杆图标。品牌标识换成日出线条。

**第 3 轮**
- 1440 右栏下半部分约 400px 空白；工单补到 5 条，右栏高度随内容。
- 375 底部导航 96% 不透明，内容在下面透出“全站发电”字样；改为实色白底。
- 375 “需要处理”项内边距稍大，三条撑满首屏；收为 12px。
