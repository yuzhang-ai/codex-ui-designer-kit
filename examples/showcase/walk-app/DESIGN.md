# 漫行 · 设计记录

状态：目标样张（target sample）。由资深设计视角逐轮手工打磨，用来说明本 Kit 在消费级移动 App 上能达到的视觉上限；**不是 Codex 一次生成的输出**。逻辑已用无头浏览器脚本验证，真人审美与真机未验收。

单文件：`index.html`（CSS / JS / 插画全部内联，无外部资源）。路线、地点、天气均为虚构演示数据，页面里以“概念演示”标注。

## 方向

一张手绘的城市散步地图，夹在一本纸质手记里。安静、好奇、温暖，不是运动记录器：不显示配速、卡路里和排名，大数字只留给“下一站叫什么”和“走了多久”。

每屏最重要的东西：

| 屏 | 最重要 | 唯一主操作 |
|---|---|---|
| 今日 | 今日推荐路线的插画卡 | 点卡片进入路线（卡片本身就是入口，没有另放实心按钮） |
| 路线详情 | 地图上的路线和 6 个站 | 开始漫行（吸底胶囊） |
| 漫行中 | 下一站名字 | 到了 |
| 手记 | 输入框 | 保存手记 |

层级：页面纸色 → 浮起的纸卡（推荐卡、下一站卡、走完卡片、已存手记）→ 卡内或页面上的内凹面（输入框、统计条、“留意”提示、继续上次）。同一层之间只靠留白，不加描边。

主按钮与背景同属暖绿家族：苔绿是 146° 的深色，不是纯黑。按 visual-taste-corrections 2.3 的规则，这是有意的例外：纸色 41° 与苔绿 146° 色相差超过 20°，理由是品牌主色就是苔绿，整套插画、地图路径和图标都用这一色，按钮跟着品牌色走，而不是跟着纸色走。

数字：全局 `lining-nums`，时间、距离、计数加 `tabular-nums`，计时跳动时数字宽度不变。

## 强调色只有三种角色

柿红只出现在：

1. **当前 / 下一站**：地图上的当前站点、站号圆、“下一站”标签、路线详情里点选的站。
2. **进度**：已走过的路径、当前位置点、“继续上次”的进度环、手记卡片的到站刻度、标签栏“漫行”上的进行中小点。
3. **失败**：手记保存失败的提示块与重试按钮（配图标和文字，不只靠颜色）。

成功状态用苔绿加对勾，不用柿红。

## 组件

- **主按钮**：苔绿胶囊，高 56，带同色投影；右侧可附一段低透明度说明（“约 52 分钟”“已到 3 / 6 站”）。不可用时变成灰苔绿并设 `aria-disabled`，例如暂停中的“到了”、空文本的“保存手记”。
- **圆按钮**：44×44，纸卡色加 `--lift`，用于地图上的返回 / 收藏。漫行中的暂停 / 继续是 56×56 的内凹面圆按钮，比“到了”轻一级。
- **推荐卡**：8px 内边距的纸卡包住插画（内圆角 20 = 28 − 8），下方是宋体路线名与元信息，右侧苔绿浅底箭头。
- **小路线卡**：横向滑动，`scroll-snap`，插画、宋体名、元信息三行，没有外框。
- **统计条**：内凹面加三列，列间 1px 竖线（职责：分开三项可比的数），这是全页唯一的分隔线。
- **站点列表**：站号圆加宋体站名、右侧里程、下方一句描述；站与站之间用 2px 点线连起来（职责：表示这是一条顺序路径，不是普通列表）。
- **下一站卡**：最大的宋体字（32px）是站名；“留意”是一句内凹面上的宋体提示，告诉你到了看什么。
- **心情标签**：内凹面胶囊；选中项用苔绿浅底、加粗、内描边和对勾，不只靠颜色。
- **状态行**：保存成功是苔绿对勾加文字；失败是柿红浅底块，配图标、两行说明和“重试”。
- **Toast**：苔绿胶囊，从顶部落下，2.2 秒后消失，用于打卡和收藏反馈。
- **标签栏**：纸色底，向上扩散阴影；当前项苔绿加粗，`aria-current="page"`。

## 图标

一套自绘线性图标，24 网格，1.8 描边（当前标签 2.1），圆头圆角，`<symbol>` 定义后 `<use>` 引用：今日（日出）、路线（折页地图）、漫行（两枚脚印）、手记、返回、收藏、箭头、chevron、暂停、继续、对勾、时钟、路径、爬升、天气、提示、笔。不用 emoji。

## 插画规则

- 全部是内联 SVG，按种子化的伪随机程序生成，每次渲染结果一致。
- **一张共用的虚构城市底图**：街区、胡同四合院、清溪河、三座桥、东园与湖、梧桐行道树、芦苇、钟楼广场。四条路线画在同一座城市里，切换路线时只换视窗和路径。
- **路径**：先画 11px 纸色“路面”压在街区上，再画 3.6px 苔绿线，用 `feTurbulence + feDisplacementMap` 做轻微手绘抖动。漫行中改成柿红实线（已走）加苔绿点线（未走）。
- **站点**：纸色圆加苔绿描边和数字；当前站是柿红实心加淡光圈；已到站是苔绿实心。
- **封面插画**：四幅场景，分别是梧桐大道上的独行者、江边落日与钢桥芦苇、胡同晾衣与包子蒸笼、湖畔水杉倒影。每幅一个主色调，叠一层 `fractalNoise` 纸纹（opacity .55）。
- 颜色只取纸色、苔绿、苔绿浅调、柿红、河水灰绿和砖黄几组，不引入新的饱和色。
- 地图是示意插画，不是真实比例，页面里已注明。

## 布局与断点

| 宽度 | 呈现 |
|---|---|
| ≥ 1100（设计于 1440） | 展示台：左上品牌和一句中文主张，右上一段说明；四台 CSS 绘制的手机（灵动岛、侧键、状态栏 SVG、Home 条）横排，缩放 0.78（整排宽 1375，放得进 1440），下方编号说明。每台手机是一个独立 App 实例。 |
| 600–1099（768） | 标题区改为纵向，手机 2×2，缩放 0.72。 |
| < 600（375） | 去掉机身、展示标题和其余三台，只留第一台 App 全屏；顶部按 `env(safe-area-inset-top)` 留白，底部标签栏按 `safe-area-inset-bottom` 抬高，四个标签都可用。`#route` / `#walk` / `#journal` 可以直接打开对应标签。 |

框内滚动时，状态栏下方会淡入一层纸色渐变遮罩，内容不会和时间、电量叠在一起。

## 交互与状态

- 今日：推荐卡和小卡片进入对应路线；“继续上次”回到进行中的漫行。
- 路线详情：返回、收藏（`aria-pressed`，配 Toast）、点站在地图上高亮该站（再点取消）、开始漫行（同一路线进行中时显示“继续漫行”）。
- 漫行中：计时基于时间戳，每秒刷新；距离按路线慢走速度推算，到下一站前停住。
  - **暂停真的暂停**：冻结时间和距离、停掉 interval，状态改为“已暂停”，数字变淡，“到了”不可用并提示先继续。
  - **到了**：按钮做一次压下、回弹并扩散柿红波纹（约 0.4 秒）；支持时调用 `navigator.vibrate(12)`；Toast 提示“已到 · 站名”；下一站卡片内容从下方滑入；地图重绘进度。第 6 站打卡后出现“走完了”卡，可进入手记。
  - 页面切到后台时不暂停计时（按时间戳计算，回来后时间是对的）。这是有意的简化，已记录。
- 手记：没有走完的路线时显示空状态和“挑一条路线”；有路线时是输入框、字数、心情和保存。
  - 空文本保存：提示“先写一句再保存”，并把焦点放回输入框。
  - 保存中：按钮显示转圈和“正在保存…”，带 `aria-busy`，输入框只读。
  - 成功：状态行显示“已保存到手记”，手记出现在下方列表，输入框清空。
  - **失败（模拟）**：文本里包含“**断网**”两个字，或页面地址带 `?fail=1`（只让第一次保存失败），就会进入失败态：柿红浅底提示“没存上，网络好像断了。文字还在，可以再试一次。”，**文字和心情都保留**，焦点移到“重试”。
- 动效：视图淡入、Toast、打卡回弹、当前位置脉冲、“漫行中”呼吸点。`prefers-reduced-motion` 下全部关掉，脉冲隐藏。`?shot=1` 也会关掉动画，只用于截图。
- 键盘：所有交互元素都是 `<button>` / `<textarea>`，`:focus-visible` 显示苔绿外圈；切换视图时焦点移到新视图标题（不画焦点框）。图标按钮都有 `aria-label`，地图有 `role="img"` 和描述。

## 已验证（2026-11-12，headless Chrome；测试页放在 /tmp，没有提交进仓库）

- 30 项桌面逻辑检查全部通过：
  - 每台手机独立互动；推荐卡、小卡片、继续上次的跳转；标签 `aria-current`；收藏；点站高亮。
  - 开始、计时跳动、暂停后 3.5 秒内时间和距离都不变、暂停时不能打卡、继续后接着计时；打卡推进、Toast、反馈动画、6 站后进入“走完了”、进行中小点消失。
  - 手记：空状态、空文本提示、保存中、保存成功（列表加 1、输入框清空、心情保留在条目上）；失败时文字保留、不新增条目，改文字后重试成功。
  - 没有走完的路线时，手记显示空状态；1440 宽度下没有横向溢出。
- 375 宽度：只显示一个 App、填满视口、四个标签都能切换、无横向溢出、所有按钮高 ≥ 40（主要按钮 56、标签项 48、图标按钮 44；心情标签是 40）、没有无名的图标按钮。
- 截图核对：1440、768（2×2，最终版 CSS 已重新截图）、375（今日 / 路线 / 漫行），以及暂停、点选站点、保存失败、走完、保存成功、手记空状态。
- 关键文字对比度：见 Tokens 表，全部 ≥ 4.5:1。
