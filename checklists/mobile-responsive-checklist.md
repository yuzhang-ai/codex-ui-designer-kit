# Mobile Responsive Checklist

用于确保桌面原型改造后在手机上也能使用。

## 布局

- [ ] 桌面多列在移动端改成单列或合理折叠。
- [ ] 侧边栏变成抽屉、顶部菜单或底部导航。
- [ ] 表格变成卡片列表、横向可控表格或关键字段摘要。
- [ ] 固定元素不遮挡主内容。

## 尺寸

- [ ] 主按钮高度至少 44px。
- [ ] 输入框高度至少 40px。
- [ ] 图标按钮有足够点击区域。
- [ ] 卡片内边距不小于 12px。

## 文本

- [ ] 标题不会超过容器或覆盖按钮。
- [ ] 长字段支持换行、省略或展开。
- [ ] 表格列名在移动端不会挤成一团。
- [ ] 不使用随 viewport 宽度无限缩放的字体。

## 表单

- [ ] label、输入、错误提示在同一上下文。
- [ ] 提交按钮靠近表单结尾或固定底部。
- [ ] 错误信息不会把布局挤坏。
- [ ] 键盘出现时关键输入和按钮仍可达。

## 状态和交互

- [ ] tab/filter 选中态明显。
- [ ] hover-only 信息在移动端有替代展示。
- [ ] 弹窗宽度适配手机。
- [ ] toast 不遮挡底部主按钮。

## QA

- [ ] 使用 390 x 844 截图。
- [ ] 检查 `document.documentElement.scrollWidth <= window.innerWidth + 2`。
- [ ] 检查小按钮和文本溢出。
- [ ] 记录移动端截图路径和失败项。
