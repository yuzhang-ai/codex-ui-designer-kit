# Customer Data Safety Checklist

用于客户运营、CRM、企微、客服、销售、营销自动化相关 UI。

## 展示前

- [ ] 确认页面使用 mock 数据或已脱敏数据。
- [ ] 客户姓名、电话、邮箱、微信、公司、合同、订单、聊天内容已按权限展示。
- [ ] 截图和报告不会暴露真实客户信息。
- [ ] 错误信息不会暴露内部系统、SQL、token、接口路径。

## 操作前

- [ ] 群发消息、邮件、短信必须先展示收件范围。
- [ ] 导出客户列表必须展示字段、数量、用途和权限提醒。
- [ ] 写回 CRM/企微/Salesforce 必须展示变更摘要。
- [ ] 删除、合并、批量修改必须二次确认。

## AI 生成内容

- [ ] AI 生成的客户话术需要人工审核。
- [ ] AI 生成的客户评分、标签、建议不能直接写回，除非用户确认。
- [ ] AI 输出需要标注来源和不确定项。
- [ ] 对外内容需要检查链接、日期、称呼和敏感词。

## 权限

- [ ] 普通用户看不到管理员操作。
- [ ] 禁用按钮说明权限不足或条件不满足。
- [ ] 访问受限详情页有安全的空状态。
- [ ] 共享链接和公开权限需要额外确认。

## 交付

- [ ] `UI_DELIVERY_REPORT.md` 列出所有人工确认点。
- [ ] 若存在真实客户数据风险，交付前必须提醒用户人工复核。
- [ ] 不把客户数据、密钥、内部链接提交到 Git。
