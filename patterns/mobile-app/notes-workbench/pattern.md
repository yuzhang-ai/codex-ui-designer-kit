# notes-workbench

## 适用场景

- 移动便签、任务、轻量项目、收藏、灵感库、个人工作台。
- App 风格 Web UI，需要列表、详情、编辑和状态闭环。

## 不适用场景

- 大型 CRM 桌面后台。
- 复杂 BI 看板。

## 推荐业务对象

便签、任务、清单、收藏、想法、待办、草稿、轻量工单。

## 页面结构

- 顶部：当前列表、搜索、筛选、创建按钮。
- 主体：分组列表或卡片流。
- 详情：编辑区、标签、状态、时间、关联对象。
- 底部：移动导航或主操作。

## 组件拆分

- `MobileShell`
- `QuickCapture`
- `NotesList`
- `NoteCard`
- `NoteEditor`
- `TagFilter`
- `BottomNav`
- `SyncStatus`

## 状态设计

- loading：列表骨架和编辑区占位。
- empty：给创建第一条、导入或示例入口。
- error：同步失败、保存失败、离线状态。
- disabled：无权限、已归档、只读。
- selected：当前便签、当前标签、当前底部 tab。

## 响应式规则

- 手机：单列，底部导航，编辑进入独立页或 drawer。
- 桌面：左列表 + 右编辑双栏。
- 触控目标：按钮至少 44px，卡片内边距 12-16px。

## 设计 token 建议

- 移动标题 18-22px，列表标题 15-17px，正文 14-16px。
- 卡片 radius 8px 内，避免一屏都是厚重卡片。
- 色彩保持轻量，状态色语义固定。

## 如何迁移到目标项目

1. 先确定对象是 note、task 还是 collection。
2. 用列表/详情/编辑闭环替代静态卡片墙。
3. 给保存、同步、离线、空列表补状态。
4. 桌面可以扩展为双栏，移动保持单任务路径。

## 可以模仿

- Todo / note 的快速捕获、标签筛选、当前选中态。
- App shell 的底部导航和单列流。

## 不要照搬

- Todoist/Things/Apple 等品牌视觉和插画。
- 移动端大面积 hero。

## 许可证和风险说明

本 pattern 为 kit 内部复合范式。公开 app 样本只作为结构参考，不复制品牌资产或源码。
